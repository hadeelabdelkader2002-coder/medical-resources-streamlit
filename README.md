# Medical Resources Across Lebanese Towns

This project is an interactive Streamlit application that explores the availability of medical resources across Lebanese towns.

## Purpose

The application allows users to explore how different medical resources are distributed across towns and investigate relationships between different types of medical facilities.

## Features

- Select a medical resource and identify the top towns for that resource.
- Compare two different medical resources across towns.
- Interactive Plotly visualizations.
- Two linked interaction features for progressive exploration of the data.
- Design explanations describing the purpose of each interaction.

## Data

The dataset contains information about medical resources across Lebanese towns, including hospitals, pharmacies, clinics, medical centers, and labs and radiology centers.
